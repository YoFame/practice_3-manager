# Личный кабинет успеваемости студента

Android-приложение на языке Kotlin для учета и анализа учебных оценок. Позволяет группировать оценки по дисциплинам, рассчитывать средний балл и отслеживать риски неуспеваемости.

## Функционал
- Просмотр общего среднего балла и количества оценок на главном экране.
- Добавление и удаление учебных дисциплин.
- Добавление, редактирование и удаление оценок (с указанием даты, типа работы и комментария).
- Автоматический расчет среднего балла по каждому предмету.
- Индикатор риска (цветовая подсветка дисциплин с низким средним баллом или недостатком оценок).

## Технологический стек
- Язык: Kotlin
- Среда разработки: Android Studio (AGP: 9.4.1)
- Интерфейс: XML (View-based), Material Design
- База данных: Room (SQLite)
- Асинхронность: Корутины (lifecycleScope)

## Инструкция по запуску
1. Клонировать репозиторий: `git clone <ссылка>`
2. Открыть проект в Android Studio.
3. Дождаться окончания Gradle Sync.
4. Запустить приложение на эмуляторе (API 24+) или реальном устройстве (кнопка Run 'app').

## Инструкция пользователя
1. **Дисциплины:** Перейдите на экран «Мои дисциплины» и нажмите «+ Добавить дисциплину». Введите название.
2. **Оценки:** Выберите дисциплину из списка. Нажмите «+ Добавить оценку», укажите значение (от 2 до 5), дату, тип работы и комментарий.
3. **Редактирование:** Нажмите на карточку оценки для изменения данных.
4. **Удаление оценки:** Сделайте долгое нажатие на карточку оценки и подтвердите удаление.
5. **Удаление дисциплины:** Сделайте долгое нажатие на карточку дисциплины. Все прикрепленные к ней оценки удалятся автоматически.
6. **Индикатор риска:** Дисциплины на экране списка подсвечиваются зеленым (все хорошо), желтым (мало оценок) или красным (низкий средний балл).

## Структура базы данных (Room)
- **Discipline:** `id`, `name`.
- **Grade:** `id`, `disciplineId`, `value`, `date`, `workType`, `comment`.

Связь один-ко-многим: одна дисциплина содержит множество оценок. Настроено каскадное удаление (при удалении дисциплины удаляются все её оценки).

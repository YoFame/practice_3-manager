# Спринт 2: Модель данных и локальное хранение (Room)

## 1. Описание сущностей (Таблиц)

**Сущность «Дисциплина» (Discipline):**
Предназначена для хранения списка предметов.
- **id** (Int, Primary Key, autoGenerate) — уникальный идентификатор.
- **name** (String) — название дисциплины (например, "Математика").

**Сущность «Оценка» (Grade):**
Предназначена для хранения оценок по предметам.
- **id** (Int, Primary Key, autoGenerate) — уникальный идентификатор.
- **disciplineId** (Int, Foreign Key) — ID дисциплины, к которой относится оценка.
- **value** (Int) — числовое значение оценки (от 2 до 5).
- **date** (String) — дата выставления оценки в формате ГГГГ-ММ-ДД.
- **workType** (String) — тип работы (Контрольная, Практическая, Лабораторная, Ответ).
- **comment** (String, nullable) — необязательный текстовый комментарий.

## 2. Связь между таблицами
- **Связь:** Одна дисциплина (Discipline) может иметь много оценок (Grade). 
- **Правило удаления (CASCADE):** Если студент удаляет дисциплину, все оценки, привязанные к этой дисциплине, должны автоматически удаляться из базы данных, чтобы не оставалось "мусора".

## 3. Правила валидации (для QA)
- Оценка должна быть строго в диапазоне от 2 до 5.
- Дисциплина не может быть создана с пустым названием.
- Дата должна быть валидной (ГГГГ-ММ-ДД).

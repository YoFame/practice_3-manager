
# ОТЧЁТ ПО СПРИНТУ №1
## Роль: Product Owner / аналитик

**Проект:** «Личный кабинет успеваемости студента»  
**Продолжительность:** 6 учебных часов  
**Спринт:** 1

## 1. Цель работы

Основной целью являлся анализ требований к приложению, определение его функциональных возможностей, описание пользовательских сценариев и планирование дальнейшей разработки.

## 2. Выполненные задачи

В ходе первого спринта были выполнены следующие задачи:

1. Изучены требования к проекту.
2. Определены основные функции приложения.
3. Составлен список экранов приложения.
4. Разработаны пользовательские сценарии.
5. Определены критерии приёмки функционала.
6. Согласованы требования к интерфейсу.
7. Составлен список задач для команды.
8. Подготовлена структура демонстрации проекта.

## 3. Основные функциональные требования

Были определены следующие функции приложения:

- Просмотр общего среднего балла.
- Просмотр списка дисциплин.
- Просмотр оценок по предметам.
- Добавление новых оценок.
- Редактирование и удаление оценок.
- Фильтрация оценок.
- Просмотр динамики успеваемости.
- Расчёт целевого среднего балла.

## 4. Пользовательские сценарии

Были разработаны следующие сценарии:

1. Просмотр общей успеваемости студента.
2. Просмотр оценок по выбранной дисциплине.
3. Добавление новой оценки.
4. Редактирование и удаление оценки.
5. Фильтрация оценок по периоду.
6. Просмотр динамики успеваемости.
7. Расчёт необходимой оценки для достижения цели.

## 5. Результаты работы

По итогам первого спринта:

- Проанализированы требования проекта.
- Сформирован перечень функциональных возможностей.
- Подготовлено описание пользовательских сценариев.
- Определены основные экраны приложения.
- Согласованы критерии приёмки.
- Сформирован список задач для следующего спринта.

## 6. Вывод

В ходе первого спринта была выполнена аналитическая работа, необходимая для начала разработки приложения. Определены основные требования, пользовательские сценарии и функциональные возможности будущего продукта.

Как Product Owner / аналитик, я подготовил основу для планирования и дальнейшей реализации проекта.

# ИНДИВИДУАЛЬНЫЙ ОТЧЁТ УЧАСТНИКА КОМАНДНОГО ПРОЕКТА
**Проект:** «Личный кабинет успеваемости студента» (Android, Kotlin)
**Участник:** Лазарев Антон
**Команда:** Лазарев Антон, Галкин Юрий, Кургачёв Егор

## Проделанная работа за 1 спринт (QA / DevOps):

### 1. Настройка инфраструктуры и контроль версий (DevOps):
- Создан удаленный Git-репозиторий на GitHub для командной работы.
- Настроен файл `.gitignore` (исключены служебные папки Android Studio, кэш и локальные настройки).
- Настроены права доступа для всех участников команды (добавлены в коллабораторы).

### 2. Проектирование интерфейса (UX/UI):
- На основе обязательных требований ТЗ создан интерактивный прототип в Figma.
- Спроектированы 4 основных экрана: «Главная страница» (сводка), «Список дисциплин», «Экран дисциплины» (список оценок), «Добавление оценки».
- Настроены выпадающие списки для выбора дисциплины и типа работы, а основные кнопки действий перенесены в нижнюю часть экрана для удобства использования.

### 3. Подготовка к тестированию (QA):
- Создан файл `TEST_CASES.md`.
- Разработаны первые базовые тест-кейсы на проверку запуска приложения, отображения главного экрана, пустых состояний (отсутствие оценок) и навигации.
- Подготовлен план проверки выпадающих списков на форме добавления оценки.

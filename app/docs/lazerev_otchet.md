Основной целью являлась подготовка требований к тестированию приложения, определение возможных ошибок, проверка логики работы будущего функционала и подготовка рекомендаций по обеспечению качества приложения.

## 2. Выполненные задачи

В ходе первого спринта были выполнены следующие задачи:

1. Изучены функциональные требования приложения.
2. Определены основные направления тестирования.
3. Составлены предварительные тест-кейсы.
4. Определены проверки корректности ввода оценок.
5. Продуманы проверки расчёта среднего балла.
6. Определены условия проверки сохранения и удаления оценок.
7. Сформированы требования к стабильности приложения.

## 3. Подготовленные тест-кейсы

| № | Проверка | Ожидаемый результат |
|---|---|---|
| 1 | Ввод оценки 5 | Оценка принимается |
| 2 | Ввод оценки 2 | Оценка принимается |
| 3 | Ввод оценки 6 | Появляется ошибка |
| 4 | Ввод оценки 1 | Появляется ошибка |
| 5 | Пустое поле оценки | Появляется предупреждение |
| 6 | Расчёт среднего балла | Отображается правильный результат |
| 7 | Отсутствие оценок | Показывается пустое состояние |
| 8 | Удаление оценки | Запись удаляется, средний балл пересчитывается |

## 4. Проверка расчётов

Для проверки алгоритма среднего балла был подготовлен пример:

Исходные оценки: 5, 4, 3, 5.

Ожидаемый результат:

```text
(5 + 4 + 3 + 5) / 4 = 4,25
```

Полученное значение должно отображаться в приложении как 4,25.

- Понятное отображение сообщений об ошибках.

- Стабильная работа приложения.

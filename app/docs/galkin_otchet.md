
# ОТЧЁТ ПО СПРИНТУ №1
## Роль: Lead Developer

**Проект:** «Личный кабинет успеваемости студента»  
**Продолжительность:** 6 учебных часов  
**Спринт:** 1

## 1. Цель работы

Основной целью являлось проектирование технической архитектуры приложения, определение структуры проекта, выбор технологий разработки и подготовка основы для реализации функционала.

## 2. Выбор технологий

Для разработки приложения были выбраны:

- Kotlin — язык программирования.
- Android Studio — среда разработки.
- Android — целевая платформа.
- MVVM — архитектура приложения.
- Room (SQLite) — локальная база данных.
- XML — технология создания пользовательского интерфейса.

## 3. Проектирование структуры проекта

Была определена следующая структура:

```text
StudentGradeTracker/
│
├── data/
│   ├── model/
│   │   ├── Subject.kt
│   │   └── Grade.kt
│   ├── database/
│   │   ├── AppDatabase.kt
│   │   └── GradeDao.kt
│   └── repository/
│       └── GradeRepository.kt
│
├── ui/
│   ├── screens/
│   └── components/
│
├── viewmodel/
│
└── MainActivity.kt
```

## 4. Проектирование моделей данных

Были определены две основные модели.

### Subject (Дисциплина)

- id — идентификатор дисциплины;
- name — название предмета;
- teacher — преподаватель.

### Grade (Оценка)

- id — идентификатор оценки;
- subjectId — идентификатор дисциплины;
- value — значение оценки;
- date — дата получения;
- workType — тип работы;
- comment — комментарий.

## 5. Правила расчёта среднего балла

Для расчёта среднего балла используется среднее арифметическое.

```text
Средний балл = сумма оценок / количество оценок
```

Допустимый диапазон оценок — от 2 до 5 включительно.

При отсутствии оценок приложение должно показывать сообщение об отсутствии данных.

## 6. Проектирование экранов

Были определены пять основных экранов:

1. Главный экран.
2. Список дисциплин.
3. Просмотр оценок по дисциплине.
4. Добавление и редактирование оценки.
5. Динамика успеваемости.

Также была разработана схема переходов между экранами.

## 7. Результаты работы

По итогам первого спринта:

- Выбраны технологии разработки.
- Определена архитектура MVVM.
- Спроектирована структура проекта.
- Определены модели данных.
- Разработаны правила расчёта среднего балла.
- Определены основные экраны приложения.
- Подготовлена техническая основа для дальнейшей разработки.

## 8. Вывод

В ходе первого спринта была выполнена техническая подготовка проекта. Определена архитектура приложения, спроектированы модели данных и структура хранения информации.
